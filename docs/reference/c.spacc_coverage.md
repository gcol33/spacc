# Combine spacc_coverage Objects

Combine multiple `spacc_coverage` objects by stacking their curve
matrices. All objects must have the same number of sites.

## Usage

``` r
# S3 method for class 'spacc_coverage'
c(...)
```

## Arguments

- ...:

  `spacc_coverage` objects to combine.

## Value

A combined `spacc_coverage` object with more seeds.
