# Code of Conduct

## Our pledge

We aim to maintain an open, friendly, and professional environment
within the spacc project. Everyone participating in the project should
feel welcome and respected, regardless of background, identity, or
experience level.

## Our standards

Expected conduct includes clear and respectful communication,
constructive feedback, openness to different approaches, and support for
people learning to contribute.

Unacceptable conduct includes personal attacks, insulting or dismissive
language, sharing private information without consent, harassment, and
hostility toward other participants.

## Responsibilities

Project maintainers clarify these standards and take fair action when
needed. They may edit, remove, or reject contributions that violate this
code or disrupt collaboration.

## Scope

This code applies to project discussions, issues, pull requests, and
related community interactions.

## Enforcement

Report conduct concerns privately to <gilles.colling051@gmail.com>.
Reports will be handled with discretion.
